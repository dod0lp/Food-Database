Database contains food with nutrients values (normalized to 100g).

User can do following:
- Choose already exisitng food as their favorite.
- Create new food as their favorite (if unfavorite, it is still in database, in theirs created foods).
- User can add general description for their own created food.
- Set weight of their favorite food (optional, multiple weights [package size, ingredient size]).
- Set price for their favorite food (optional, once for each size).
- User can see nutritional values per package.
- User can see prices and weights per 100g of food (based on theirs package sizes and price).
